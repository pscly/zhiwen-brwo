# 交付说明 · v0.8.40

## 本版内容
- 扩展库目录固定成 `<slug>`，不再带版本号。未打包扩展的 ID 由加载路径推导，目录带版本会让 ID 每次升级都变，用户看到的是「扩展升级后登录态/脚本全丢」。
- 新增 `POST /api/v1/maintenance/extensions/repair`，把历史遗留的旧 ID 存储目录搬到当前 ID：复制 + 原子替换，目标已有数据不覆盖，旧目录改名 `.migrated` 保留可回滚。
- 扩展商店安装同步改为固定目录与原子替换，版本号存进 `.zw-ext-meta.json`。
- 实测：四个环境（a01–a04）五个扩展的存储条目在迁移前后完全一致，Bitwarden 保持登录态。

## 发布操作

发布工作流在构建前校验源码、包元数据、Hub 镜像与标签版本，并用实际可执行文件的自检报告再核对版本。Windows 安装器使用同一校验结果。提交发布变更并推送 `v0.8.40` 标签后，Actions 构建和发布对应资产。公开发布完成后，以 [Releases](https://github.com/pscly/zhiwen-brwo/releases) 上的资产和校验和为准。

```bash
python scripts/check-release-version.py --tag v0.8.40
bash scripts/check-all.sh
# 推送标签并完成构建后，下载发布资产验收
bash scripts/verify-release.sh v0.8.40
```
