# 交付说明 · v0.8.41

## 本版内容
- 修扩展 ID 推导的路径编码：Windows 用 UTF-16LE（Chromium 的路径是 wstring），以前一律 UTF-8，算出的 ID 与浏览器实际使用的不一致，导致「数据写到了错目录」。
- 云电脑实测对照：`bitwarden-password-manager-2026.10.2` → `ccgniplcdaeapohoocjeongbfnnihnjp`；UTF-16LE 吻合，UTF-8 得到 `ldodelkf...` 不吻合。
- 新增 `packs.path_bytes()` 与真机对照单测。
- 配合上版的固定目录与 `maintenance/extensions/repair`，扩展升级后 ID 不再变，历史和现有的存储也能正确迁移。

## 发布操作

发布工作流在构建前校验源码、包元数据、Hub 镜像与标签版本，并用实际可执行文件的自检报告再核对版本。Windows 安装器使用同一校验结果。提交发布变更并推送 `v0.8.41` 标签后，Actions 构建和发布对应资产。公开发布完成后，以 [Releases](https://github.com/pscly/zhiwen-brwo/releases) 上的资产和校验和为准。

```bash
python scripts/check-release-version.py --tag v0.8.41
bash scripts/check-all.sh
# 推送标签并完成构建后，下载发布资产验收
bash scripts/verify-release.sh v0.8.41
```
