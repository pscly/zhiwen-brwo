# 01 · 快速开始

> 目标：**20 分钟**内在一台机器上把第一个环境跑起来，并且知道怎么验证它是对的。

---

## 一、Windows（推荐路径，一键）

### 1. 装 Python

需要 **3.11 或更高**。从 <https://www.python.org/downloads/windows/> 装，
安装时**务必勾选 `Add python.exe to PATH`**。

```powershell
python --version      # 期望 3.11+
```

> 有 `uv` 更好（`winget install astral-sh.uv`），没有也能跑，只是建环境慢一点。

### 2. 拿代码

```powershell
git clone https://github.com/pscly/zhiwen-brwo.git C:\dev\zhiwen_brwo
cd C:\dev\zhiwen_brwo
```

> 路径**必须是纯英文、不带空格**。`C:\用户\张三\...` 这种会让某些内核参数解析出问题。

### 3. 一键部署

```powershell
.\scripts\windows\部署.cmd
```

脚本会依次：建 `.venv` → 装依赖 → **随机生成**访问令牌与同步主密码写进 `.env` →
自动找系统里的 Chrome → 启动服务。

**屏幕上会把两个值打出来，抄下来：**

```
>> 你的访问令牌：zw_xxxxxxxxxxxx
>> 你的同步主密码：yyyyyyyyyyyy     （丢了这个就解不开远端快照）
```

期望：浏览器打开 <http://127.0.0.1:8730>，看到控制台，左上角显示你的主机名与内核版本。

### 4. 换指纹内核（要做，否则多个环境是"同一台设备"）

系统 Chrome 能用，但**不支持 `--fingerprint`**：环境之间只有 cookie 隔离，指纹完全一样。
要真正一号一设备，用 fingerprint-chromium：

```powershell
$dir = "$env:LOCALAPPDATA\zhiwen\engines"
New-Item -ItemType Directory -Force -Path $dir | Out-Null
cd $dir
# 国内直连 GitHub 会超时，可以先挂代理
Invoke-WebRequest -Uri "https://github.com/adryfish/fingerprint-chromium/releases/download/150.0.7871.186/ungoogled-chromium_150.0.7871.186-1.1_windows_x64.zip" -OutFile fp.zip
Expand-Archive fp.zip -DestinationPath .
Get-ChildItem -Recurse -Filter chrome.exe | Select-Object -First 1 FullName
```

然后把 `.env` 里的 `ZW_CHROME_BIN` 指到那个 `chrome.exe`，重启服务。

> 杀软可能报这个未签名构建，把 `%LOCALAPPDATA%\zhiwen\engines` 加白名单。
> 作者也给了夸克网盘：<https://pan.quark.cn/s/9bb65af874fb>

### 5. 验证

```powershell
.\scripts\windows\自检.cmd        # 快速自检（不启动浏览器）
.\scripts\windows\全量自检.cmd    # 完整自检（真开浏览器，约 2 分钟）
```

期望：快速自检全 `[OK]`；全量自检 `通过 60+ 项，失败 0 项`。

## 二、Linux / macOS

### 1. 装依赖

```bash
git clone https://github.com/pscly/zhiwen-brwo.git zhiwen_brwo && cd zhiwen_brwo

# 需要 uv（没有就：curl -LsSf https://astral.sh/uv/install.sh | sh）
uv venv .venv
uv pip install --python .venv/bin/python -e ./core -e ./hub
```

> Ubuntu 上如果 `python3 -m venv` 报 `ensurepip is not available`：
> `sudo apt install python3.12-venv`

### 2. 准备内核

```bash
# 方案 A：系统包（最省事，但没有 --fingerprint）
sudo apt install chromium

# 方案 B：fingerprint-chromium（推荐）
mkdir -p ~/.local/share/zhiwen/engines && cd $_
curl -LO https://github.com/adryfish/fingerprint-chromium/releases/download/150.0.7871.186/ungoogled-chromium-150.0.7871.186-1-x86_64_linux.tar.xz
tar xf ungoogled-chromium-*.tar.xz
chmod +x ungoogled-chromium-*/chrome
```

程序会在 `<数据目录>/engines/` 下递归找 `chrome`；也可以用 `ZW_CHROME_BIN` 直接指路。

### 3. 启动

```bash
export ZW_ADMIN_TOKEN=自己定一个足够长的串
export ZW_CHROME_BIN=/path/to/chrome      # 用系统 chrome 时可不设
.venv/bin/python -m zw_core.main          # 打开 http://127.0.0.1:8730
```

### 4. 自检

```bash
zw doctor                                  # 快速自检
ZW_ADMIN_TOKEN=... ZW_SYNC_PASSWORD=... \
  python scripts/e2e-check.py              # 完整自检（63 项）
```

## 三、建第一个环境

### 用控制台

打开 <http://127.0.0.1:8730> → 左上「＋ 新建环境」→ 填名字 → 建。
列表里点「启动」→ 点「CDP」拿连接地址 → 点「更多 → 指纹体检」看这台机器的真实指纹。

### 用命令行

```bash
zw profile create --name 我的第一个环境 --timezone Asia/Shanghai --lang zh-CN
zw profile start  我的第一个环境
zw profile cdp    我的第一个环境      # 打印可直接用的 ws 地址与 Playwright 片段
zw profile probe  我的第一个环境      # 指纹体检
```

`zw profile cdp` 的输出可以直接贴进 Playwright：

```python
from playwright.sync_api import sync_playwright

with sync_playwright() as pw:
    browser = pw.chromium.connect_over_cdp("<打印出来的 ws 地址>")
    page = browser.contexts[0].pages[0]
    page.goto("https://example.com")
```

> 地址里的 `token=` 是短期凭证（默认 15 分钟），过期重新执行一次命令拿新的。

## 四、接上同步中心（可选）

如果你有第二台机器，或者想换机器时把登录态带走：

1. 在**一台常开的机器**上部署 hub（已经部署在 `192.168.3.5:8700`，见 [部署指南](03-部署指南.md)）。
2. 在每台 core 的 `.env` 里加：

```
ZW_HUB_URL=http://192.168.3.5:8700
ZW_HUB_TOKEN=<hub 的令牌>
ZW_SYNC_PASSWORD=<主密码，千万别丢>
```

3. 源机推送：控制台 → 同步 → 填主密码 → 「推送」，或者 `zw sync push 我的第一个环境`
4. 目标机拉取：`zw sync pull <环境id>` —— **本地没有这个环境也会自动导入**，
   连代理、窗口尺寸、时区、分组一起搬过去。

### 只有一台机器？用导出包

控制台 → 环境 → 更多 → 「导出 .zwp」，得到一个加密单文件；
换机器后用 `zw profile import 文件.zwp` 还原。内容和同步包一样，只是不过 hub。

## 五、常见第一次踩坑

| 现象 | 原因 | 解决 |
|---|---|---|
| `ENGINE_NOT_FOUND` | 没找到内核 | 设 `ZW_CHROME_BIN`，或把内核放进 `<数据目录>/engines/` |
| `ENGINE_EXITED`，日志里 `Missing X server` | Linux 无图形界面 | 程序会自动加 `--headless=new`；仍失败就装 `xvfb` |
| `PORT_MISMATCH` | 分配的端口上有别的进程在响应 | 维护页点「清理孤儿进程」；或改 `.env` 里的端口池（Windows 上常见是 Hyper-V 占了） |
| 启动后 WebGL 是 `null` / `SwiftShader` | 机器没有可用 GPU | 正常现象。**要过指纹检测请用有显卡的 Windows** |
| 控制台打不开 | 端口被占 / 没起来 | `zw stats` 看服务状态；或看 `<数据目录>/logs/zhiwen.log` |
| 提示需要令牌 | 设了 `ZW_ADMIN_TOKEN` | 控制台会弹登录卡，粘进去；忘了就看 `.env` |
| 指纹体检报"平台不一致" | 用的是系统 Chrome，`--fingerprint-platform` 被忽略 | 换 fingerprint-chromium |
| 改了代理/扩展不生效 | 启动参数只在启动时读 | 重启环境（响应里有 `needs_restart` 提示） |

数据目录默认位置：

- Windows：`%LOCALAPPDATA%\zhiwen`
- Linux/macOS：`~/.local/share/zhiwen`

想换位置就设 `ZW_ROOT`。
