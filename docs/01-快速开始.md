# 01 · 快速开始

> 目标：15 分钟内在一台机器上把第一个环境跑起来。

---

## 一、准备浏览器内核

知纹本身不带浏览器，它只负责"管"。你需要一个 Chromium 系内核，二选一：

### 方案 A：用系统已有的 Chrome / Chromium（最省事）

- **Windows**：装了 Chrome 就行，程序会自动在注册表常见路径找到它。
- **Linux**：`sudo apt install chromium` 或已有 `google-chrome` 即可。

### 方案 B：用 fingerprint-chromium（推荐，指纹可持久化）

它是唯一支持 `--fingerprint=<种子>` 的开源内核，**同一个种子 = 同一台"设备"**，
这是跨机同步指纹能成立的前提。

```bash
# Linux
mkdir -p ~/.local/share/zhiwen/engines && cd $_
curl -LO https://github.com/adryfish/fingerprint-chromium/releases/download/150.0.7871.186/ungoogled-chromium-150.0.7871.186-1-x86_64_linux.tar.xz
tar xf ungoogled-chromium-*.tar.xz
chmod +x ungoogled-chromium-*/chrome
```

```powershell
# Windows（PowerShell）
$dir = "$env:LOCALAPPDATA\zhiwen\engines"
New-Item -ItemType Directory -Force -Path $dir | Out-Null
cd $dir
Invoke-WebRequest -Uri "https://github.com/adryfish/fingerprint-chromium/releases/download/150.0.7871.186/ungoogled-chromium_150.0.7871.186-1.1_windows_x64.zip" -OutFile fp.zip
Expand-Archive fp.zip -DestinationPath .
```

> 国内直连 GitHub release 可能超时，可以走你的代理，或者手动下载后解压到同样的目录。

程序会在这个目录下递归找 `chrome.exe` / `chrome`。也可以用环境变量 `ZW_CHROME_BIN` 直接指路。

## 二、安装知纹

### Linux / macOS

```bash
git clone <本仓库> zhiwen_brwo && cd zhiwen_brwo

# 需要 uv（没有就先装：curl -LsSf https://astral.sh/uv/install.sh | sh）
uv venv .venv
uv pip install --python .venv/bin/python -e ./core -e ./hub
```

### Windows

```powershell
git clone <本仓库> zhiwen_brwo
cd zhiwen_brwo

# 需要 Python 3.11+ 与 uv
uv venv .venv
.venv\Scripts\activate
uv pip install -e ./core
```

> Windows 上不需要装 hub（同步中心只部署一次，放一台常开的机器上）。

## 三、启动

### Linux

```bash
export ZW_ADMIN_TOKEN=自己定一个足够长的串
export ZW_CHROME_BIN=/path/to/chrome      # 或用系统 chrome 时可不设
.venv/bin/python -m zw_core.main
```

### Windows

```powershell
$env:ZW_ADMIN_TOKEN="自己定一个足够长的串"
.venv\Scripts\python -m zw_core.main
```

或者双击 `scripts\windows\启动.cmd`（第一次会让你填令牌并写进用户环境变量）。

启动后打开 **http://127.0.0.1:8730** —— 那就是控制台。

### 第一次自检

```bash
zw doctor
```

期望看到：

```
浏览器内核  ✅  Chromium 150.0.7871.186
数据库      ✅
访问令牌    ✅  已配置
数据目录    ✅
并发余量    ✅
```

如果"浏览器内核"是 ❌，回到第一步。

## 四、建第一个环境

### 用控制台

打开 http://127.0.0.1:8730 → 右上角「＋ 新建环境」→ 填名字 → 确认。

### 用命令行

```bash
zw profile create --name 我的第一个环境
zw profile start  我的第一个环境
zw profile cdp    我的第一个环境
```

`zw profile cdp` 会打印一段可直接用的 Playwright 代码：

```python
from playwright.sync_api import sync_playwright
with sync_playwright() as pw:
    b = pw.chromium.connect_over_cdp("<打印出来的 ws 地址>")
    page = b.contexts[0].pages[0]
    page.goto("https://example.com")
```

## 五、接上同步中心（可选）

如果你有第二台机器，或者想换机器时把登录态带走：

1. 在**一台常开的机器**上部署 hub（已部署在 `192.168.3.5:8700`，见 [部署指南](03-部署指南.md)）。
2. 在每台 core 上设置：

```bash
export ZW_HUB_URL=http://192.168.3.5:8700
export ZW_HUB_TOKEN=<hub 的令牌>
export ZW_SYNC_PASSWORD=<主密码，千万别丢>
```

3. 源机推送：

```bash
zw sync push 我的第一个环境
```

4. 目标机拉取（**本地没有这个环境也行，会自动导入**）：

```bash
zw sync pull <环境id>
```

## 六、常见第一次踩坑

| 现象 | 原因 | 解决 |
|---|---|---|
| `ENGINE_NOT_FOUND` | 没找到内核 | 设 `ZW_CHROME_BIN`，或把内核放进 `<数据目录>/engines/` |
| `ENGINE_EXITED`，日志里 `Missing X server` | Linux 无图形界面 | 程序会自动加 `--headless=new`；如果仍然失败，装 `xvfb` |
| 启动后 WebGL 是 `null` | 机器没有 GPU | 正常。**要过指纹检测请用有显卡的 Windows** |
| 控制台打不开 | 端口被占 / 没起来 | `zw stats` 看服务状态；或看 `<数据目录>/logs/zhiwen.log` |
| 提示需要令牌 | 你设了 `ZW_ADMIN_TOKEN` | 浏览器 localStorage 里存的是旧令牌，清掉或重新输入 |

数据目录默认位置：

- Windows：`%LOCALAPPDATA%\zhiwen`
- Linux：`~/.local/share/zhiwen`

想换位置就设 `ZW_ROOT`。
