# 交付说明 · v0.8.39

## 本版内容

- 新增 `ZW_SOFTWARE_GL` 配置项，默认关闭。无显卡机器（云电脑/虚拟机/远程桌面）开启后 WebGL 才可用。
- 取值：`warp`（微软 Basic Render Driver，真实无显卡 Windows 原生就是这个）、`swiftshader`（Chromium 自带）、`auto`（Windows 用 warp、其它平台用 swiftshader）。
- 真机实测：不加参数 WebGL 为 null；warp 得到 `ANGLE (Microsoft, Microsoft Basic Render Driver (0x0000008C) Direct3D11 vs_5_0 ps_5_0, D3D11)`；swiftshader 暴露 `SwiftShader Device (Subzero)`，观感更差。
- 有独立显卡的机器保持关闭，真实 GPU 不被替换。
- 相关说明见 [部署指南](03-部署指南.md#4-配置)。

## 发布操作

发布工作流在构建前校验源码、包元数据、Hub 镜像与标签版本，并用实际可执行文件的自检报告再核对版本。Windows 安装器使用同一校验结果。提交发布变更并推送 `v0.8.39` 标签后，Actions 构建和发布对应资产。公开发布完成后，以 [Releases](https://github.com/pscly/zhiwen-brwo/releases) 上的资产和校验和为准。

```bash
python scripts/check-release-version.py --tag v0.8.39
bash scripts/check-all.sh
# 推送标签并完成构建后，下载发布资产验收
bash scripts/verify-release.sh v0.8.39
```
