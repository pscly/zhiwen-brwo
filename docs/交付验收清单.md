## 一、代理导入（需求原文的 `socks5://user:pass@host:port`）

| 验法 | 应该看到 |
|---|---|
| 控制台「代理」→「导入代理」，粘一串带密码的 socks5 | 导入成功，列表里 IP/端口**完整可见**，密码显示为 `***` |
| 再粘一次同一串 | 提示重复跳过，不会多出一条 |
| 粘 `http://127.0.0.1:7890` | 也支持（不只 socks5） |
| 故意写错（如 `66.80.12 0.66:20000` 中间多空格） | 被拒，并给出**可读原因** ✅ 真机验过 |

支持链路代理：`前置,落地` 两段写法（前置负责连，落地负责出口）。

## 二、客户端控制台：本机免令牌

| 验法 | 应该看到 |
|---|---|
| 在**装有客户端的那台机器**上打开 `http://127.0.0.1:8730` | **直接进**，不弹令牌框 ✅ 真机验过（`auth_required=false`，host 是 `0.0.0.0`） |
| 从**另一台机器**打开 `http://<它的IP>:8730` | 要求输入**机器码** ✅ 真机验过（401 → 填机器码 → 200） |
| 改端口：配置文件写 `ZW_PORT=8731` 后重启 | 监听变成 8731 ✅ |

## 三、创建完浏览器后还能改代理

| 验法 | 应该看到 |
|---|---|
| 建一个环境 → 启动 → 点「代理」改成另一条 → 重启 | 新代理生效 ✅ 真机验过 |
| 改成**不带密码**的代理 | 命令行是 `--proxy-server=socks5://host:port`（直连上游）✅ |
| 改成**带密码**的代理 | 命令行变成 `--proxy-server=http://127.0.0.1:<端口>`（本机中继代填凭据），并给一条说明 ✅ |

## 四、启动后先恢复上次网页，再加检测页

| 验法 | 应该看到 |
|---|---|
| 新建环境 → 启动 | 自动打开 3 个检测页 ✅ 真机 CDP 读到 3 个 page |
| 在里面多开几个网页 → 停止 | 返回 `remembered: {saved: N}` ✅ 真机 `saved: 3` |
| 再启动 | 恢复上次那些页 + 检测页，**不重复** ✅（0.7.64 修过 `ip123.in` 跳转导致的重复） |

三个检测页与用途（都实测 200）：

| 网址 | 看什么 |
|---|---|
| `browserleaks.com/ip` | 出口 IP、WebRTC 是否泄漏真实 IP |
| `ip123.in` | 中文 IP 干净度：欺诈评分、代理/VPN 特征、原生/机房 |
| `abrahamjuliot.github.io/creepjs/` | 浏览器指纹（FP ID、fuzzy hash、时区语言一致性） |

## 五、插件及其数据打包、默认带上、可关闭

| 验法 | 应该看到 |
|---|---|
| 「扩展包」面板 →「从 Chrome 目录导入」→ 点「**扫描本机**」 | 列出本机所有可导入的浏览器（带名字和扩展数）✅ 云电脑 Windows 实测：扫到 Edge(2)/Chrome(1) |
| 选一条 → 勾「设为默认」→ 导入 | 返回 `extension_count>0`、`is_default=true` ✅ `as_default` 真机确认生效（0.7.68 修过它失效） |
| 新建一个环境 | **自动带上**那些扩展 ✅ 真机：新环境 `extensions` 里就有 |
| 不想要的环境里取消勾选那个包 | 该环境不再带（这就是"也可以选择关闭"）✅ |
| 启动后想看插件到底加载没 | 环境详情里的 `extensions_active` 如实说明 ✅ 官方 Chrome 157 判 `false`（内核忽略 `--load-extension`） |

> ⏳ **只差这一步需要你**：RXYCDP 装在你的电脑上（云电脑翻遍 C/D 盘确认没有）。
> 在你机器上点一次「扫描本机」，选 RXYCDP 那条导入即可。
> 详细步骤见 [RXYCDP导入指引](RXYCDP导入指引.md)。

## 八、当前明确**没有**做的事（如实说明）

| 项 | 状态 |
|---|---|
| 指纹能否过 browserscan | **未验证** —— 需要 fingerprint-chromium 内核 + 真实站点打分 |
| fingerprint-chromium 的种子一致性 | **未验证**（同一台机器上没有该内核） |
| 带认证的**真实**上游代理握手 | **未验证** —— 你的落地代理只能经前置访问，本仓库所在网络连不到 |
| Firefox 引擎 | **不做** —— Firefox 没有 CDP；改用本机中继解决认证代理，不需要换内核 |
