# 05 · AI 接入指南

> 知纹不是"顺便给个接口"，而是**假设 AI 是主要使用者**来设计的。
> 这篇讲三层：怎么挂上、挂上后怎么用、以及为什么这么设计。

---

## 一、三层接入方式

| 方式 | 适用 | 命令 / 地址 |
|---|---|---|
| **MCP over stdio** | Claude Desktop、Cursor、Codex、任何本地 AI 客户端 | `zw mcp` |
| **MCP over HTTP** | 远端 AI、常驻 agent、多人共用 | `POST http://<core>:8730/mcp` |
| **REST** | 脚本、你自己的 agent 循环 | `http://<core>:8730/api/v1/*` |

三者能力等价（同一份实现），区别只是传输。

---

## 二、最省事的做法：让 AI 自己发现

在给 AI 的系统提示里只写一句：

```
知纹的运行地址是 http://192.168.3.x:8730，令牌在 ZW_ADMIN_TOKEN。
开始前先 GET /api/v1/ai/manifest 读一遍。
```

`/api/v1/ai/manifest` 返回的东西是**为模型写的**，不是给人看的：

```json
{
  "一句话": "一台机器上的指纹浏览器机群：……",
  "核心概念": { "profile": "…", "fp_seed": "…", "cdp": "…", "state": "…" },
  "标准作业流程": {
    "第一次用": ["GET /api/v1/ai/manifest", "GET /api/v1/profiles", "POST /api/v1/profiles"],
    "要操作网页": ["POST /profiles/{id}/start", "取 data.cdp.gateway_ws_url", "connectOverCDP"],
    "要在另一台机器接着用": ["源机 push", "目标机 pull"]
  },
  "重要约束": ["cookie 只能从 running 的环境读写", "同一环境同一时刻只能一个持有者", "…"],
  "错误码速查": { "PROFILE_BUSY": "别的进程/机器正持有它…", "KEY_FINGERPRINT_MISMATCH": "主密码不对，**不要重试**" },
  "端点清单": [ … ]
}
```

**为什么这么做**：模型不需要先读一份 5000 字的文档才知道该调哪个接口；
它读一个 JSON 就能开工。文档是给人看的，manifest 是给模型看的。

## 三、MCP 挂载

### Claude Desktop

`claude_desktop_config.json`：

```json
{
  "mcpServers": {
    "zhiwen": {
      "command": "C:\\path\\to\\zhiwen_brwo\\.venv\\Scripts\\python.exe",
      "args": ["-m", "zw_core.mcp_server"],
      "env": {
        "ZW_ROOT": "C:\\Users\\你\\AppData\\Local\\zhiwen",
        "ZW_ADMIN_TOKEN": "你的令牌"
      }
    }
  }
}
```

### Cursor / Claude Code

```bash
claude mcp add zhiwen -- <python 路径> -m zw_core.mcp_server
```

或者直接用 HTTP 版：

```bash
claude mcp add --transport http zhiwen http://192.168.3.x:8730/mcp
```

### 23 个工具一览

| 分类 | 工具 |
|---|---|
| 环境 | `zw_list_profiles` `zw_create_profile` `zw_start_profile` `zw_stop_profile` `zw_restart_profile` `zw_get_cdp` `zw_profile_stats` |
| 数据 | `zw_read_cookies` `zw_write_cookies` `zw_read_storage` |
| 页面 | `zw_navigate` `zw_evaluate` `zw_page_text` `zw_screenshot` `zw_click` `zw_type` `zw_list_tabs` |
| 同步 | `zw_sync_push` `zw_sync_pull` `zw_sync_diff` `zw_sync_index` |
| 排错 | `zw_doctor` `zw_read_logs` |

每个工具都有完整的 `inputSchema`，模型不需要猜参数。

## 四、给 AI 的推荐作业顺序

### 场景 1：帮我打开某站点并截图

```
1. zw_list_profiles            → 看有没有现成环境
2. zw_start_profile(profile)   → 返回 gateway_ws_url
3. zw_navigate(profile, url)
4. zw_screenshot(profile)
```

### 场景 2：把这个环境的登录态搬到另一台机器

```
1. zw_sync_diff(profile)       → 看本地和远端各是什么版本
2. zw_sync_push(profile)       → 源机推
   （在目标机上执行）
3. zw_sync_pull(<profile_id>)  → 目标机会自动导入
4. zw_read_cookies(profile)    → 验证 cookie 真的在
```

### 场景 3：批量做同一件事

```
1. zw_list_profiles(state="stopped")
2. 逐个 zw_start_profile
3. 对每个 zw_navigate + zw_evaluate
4. 收尾 zw_stop_profile
```

> 并发建议：一次最多同时开 5–8 个（`ZW_MAX_RUNNING` 默认 20，但机器会先撑不住）。

## 五、"AI 原生"到底体现在哪（六条）

| # | 设计 | 为什么对 AI 重要 |
|---|---|---|
| 1 | `GET /api/v1/ai/manifest` 自描述 | 不用先读文档，省上下文 |
| 2 | 统一 `{ok, code, message, hint}` | 模型可以按 `code` 走分支，不用猜自然语言 |
| 3 | 每个错误都带 `hint`（一句话可执行建议） | 模型读到就能自我修正 |
| 4 | 幂等：`start` 已启动返回 200、`stop` 已停止返回 200 | 模型重试不会制造副作用 |
| 5 | MCP 工具描述里写清"什么时候该用它" | 工具选择更准，少乱调 |
| 6 | 日志同时输出 JSON 行 + 人类可读行 | AI 可以 `grep`/`jq` 精确排错 |

**还有两个细节**：

- **状态可直接轮询**：`GET /api/v1/events?since=<ts>` 一次返回"最近发生了什么 + 现在什么状态"，
  比让模型自己拼多个请求省 token。
- **长任务有明确边界**：`POST /profiles/{id}/start` 等 CDP 就绪才返回（最多 45 秒），
  不会出现"接口返回成功但其实还没起来"的歧义。

## 六、典型提示词模板

### 巡检

```
你是这台机器的运维。用 zhiwen 的 MCP 工具做一次巡检：
1. zw_doctor 看自检
2. zw_list_profiles 找 state 不是 running/stopped 的
3. 对 crashed 的调 zw_read_logs 看原因
4. 给出"要不要手动处理"的结论，不要自己乱重启
```

### 同步核对

```
对比本机与同步中心：
1. zw_sync_index 列出远端所有环境
2. zw_list_profiles 列出本地
3. zw_sync_diff 逐个看差异
4. 输出一张表：环境名 / 本地版本 / 远端版本 / 建议动作
不要执行 push/pull，只给建议。
```

### 页面抓取

```
在环境 <name> 里打开 https://example.com，
把它首屏的标题、主要链接文本抓出来，
如果遇到"需要登录"，停下来告诉我，不要尝试输入任何账号密码。
```

## 七、给它『手』和『刹车』

| 想做 | 怎么做 |
|---|---|
| 让 AI 只能看不能动 | 只挂 `zw_list_profiles` / `zw_read_cookies` / `zw_page_text` 这几个只读工具 |
| 让 AI 不能删环境 | 工具集里**没有** `zw_delete_profile`（删环境只给 CLI/控制台） |
| 限制并发 | 调小 `ZW_MAX_RUNNING` |
| 限制敏感操作 | 同步类工具需要主密码；不把 `ZW_SYNC_PASSWORD` 给 AI 环境即可 |

> 设计取态：**危险操作（删环境、重置指纹、强制覆盖远端）故意不放 MCP**，
> 只留在 CLI 和控制台里。AI 能做的都是可恢复的。
