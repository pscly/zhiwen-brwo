# 04 · 接口文档

> 三句话先记住：
> 1. 成功一律 `{"ok": true, "data": {...}}`；失败一律 `{"ok": false, "code", "message", "hint"}`。
> 2. `code` 是稳定字符串，给程序/AI 判断用；`message` 是人看的；`hint` 是一句话建议。
> 3. 鉴权：`Authorization: Bearer <ZW_ADMIN_TOKEN>`（不设令牌时只允许本机回环）。

在线交互文档：启动后访问 **http://127.0.0.1:8730/docs**（FastAPI 自动生成，端点全集以它为准）。

二进制端点（截图、导出包）**不套** `{ok,data}`，直接返回字节流。
时间字段统一是 Unix 秒（float）。

## 二、环境管理

| 方法 | 路径 | 说明 |
|---|---|---|

> 0.1.0 就是因为顺序错了，`import` 被当成"环境名叫 import"。改路由时注意。

### 创建

```bash
curl -s -X POST http://127.0.0.1:8730/api/v1/profiles \
  -H "Authorization: Bearer $T" -H 'Content-Type: application/json' \
  -d '{"name":"小红一号","group_name":"小红书",
       "proxy":"http://127.0.0.1:7890",
       "fp_timezone":"Asia/Shanghai","fp_lang":"zh-CN",
       "start_urls":["https://www.xiaohongshu.com"]}'
```

只有 `name` 必填。指纹种子留空会自动分配（且全局唯一）。

**可写字段全集**（`PATCH` 同一份，`fp_seed` 除外）：

```
name, group_name, tags[], note,
fp_platform, fp_platform_version, fp_brand, fp_brand_version, fp_hardware,
fp_timezone, fp_lang, fp_accept_lang, fp_disable_spoofing, fp_ua,
proxy, proxy_id, start_urls[], window_w, window_h, extensions[],
restart_policy, headless, ephemeral, trim_on_stop, sync_enabled, cdp_enabled
```

**会被挡在入库前的错误输入**（都是为了不让它在启动时才炸）：

| code | 触发 |
|---|---|
| `INVALID_NAME` | 空名 / 超 64 字符 |
| `INVALID_WINDOW` | 窗口不在 320×240 – 8192×8192 |
| `INVALID_PLATFORM` | `fp_platform` 不在 host/windows/linux/macos |
| `INVALID_RESTART_POLICY` | 不在 never/on-failure/always |
| `INVALID_TIMEZONE` | 不是合法 IANA 时区 |
| `INVALID_URL` | 起始网址不是 http/https/about/file/chrome |
| `PROXY_SCHEME_UNSUPPORTED` / `PROXY_INVALID` | 代理协议或地址不合法 |

### 启动 + 返回

```json
{"ok":true,"data":{
  "profile":{"id":"4c1f…","name":"小红一号","state":"running","fp_seed":281456832},
  "already_running": false,
  "cdp":{
    "gateway_ws_url":"ws://192.168.3.6:8730/cdp/4c1f…/devtools/browser/<GUID>?token=zwc_…",
    "playwright":"await chromium.connectOverCDP('ws://…')",
    "puppeteer":"await puppeteer.connect({ browserWSEndpoint: 'ws://…' })",
    "raw_cdp_json":"http://192.168.3.6:8730/cdp/4c1f…/json/version?token=zwc_…",
    "token_ttl":900
  },
  "local":{"pid":12345,"port":21001}
}}
```

幂等：环境已在运行时返回 `already_running: true`，不会重复拉起（重复拉起会撞 SingletonLock）。

改过 `proxy` / `extensions` / `fp_timezone` / 窗口尺寸等启动参数后，响应里会有
`needs_restart: ["proxy"]` 与 `restart_hint` —— **必须 restart 才生效**，程序不擅自替你重启。

## 三、指纹体检

```bash
curl -s -X POST http://127.0.0.1:8730/api/v1/profiles/小红一号/fingerprint/probe \
  -H "Authorization: Bearer $T"
```

返回真机实际暴露的值 + 自洽性警告：

```json
{"ok":true,"data":{
  "ua":"Mozilla/5.0 (Windows NT 10.0; Win64; x64) …",
  "platform":"Win32", "vendor":"Google Inc.",
  "ua_data":{"brands":[{"brand":"Chromium","version":"150"}],"mobile":false,"platform":"Windows"},
  "timezone":"Asia/Shanghai", "timezone_offset":-480,
  "languages":["zh-CN"], "lang":"zh-CN",
  "hardware_concurrency":22, "device_memory":8,
  "webgl_vendor":"Google Inc. (NVIDIA)",
  "webgl_renderer":"ANGLE (NVIDIA, NVIDIA GeForce RTX 3060 … Direct3D11 vs_5_0 ps_5_0, D3D11)",
  "canvas_hash":"e6e2f6cb", "audio_hash":"124.0434",
  "webdriver":false,
  "screen":{"width":1280,"height":800,"colorDepth":24,"availWidth":1280},
  "fonts_count":6,
  "warnings":[]
}}
```

`warnings` 是**启发式**判断，专门抓"内部自相矛盾"：

| 警告文本 | 含义 |
|---|---|
| `navigator.webdriver = true` | 任何风控都一眼认出这是自动化 |
| `WebGL 渲染器为空` | 这台机器没有 GPU，指纹异常（真人机器不会这样） |
| `WebGL 走的是 SwiftShader` | 典型无显卡/无头特征 |
| `outerWidth/outerHeight 为 0` | headless 特征 |
| `环境声明平台是 windows，但 navigator.platform 是 'Linux x86_64'` | 内核没生效（大概率是没用 fingerprint-chromium） |
| `环境设定时区 X，但浏览器报告 Y` | 时区参数没应用 |
| `环境设定语言 X，但 navigator.language 是 Y` | 语言参数没应用 |

> 这只是**本地自洽性**检查。指纹能不能过真实风控必须去 browserscan / creepjs 实测。

## 四、CDP 网关

| 方法 | 路径 | 鉴权 | 说明 |
|---|---|---|---|
| GET | `/cdp/{id}/json/version?token=` | 短期令牌 | 发现接口，**地址已重写** |
| GET | `/cdp/{id}/json/list?token=` | 短期令牌 | 目标列表，**地址已重写** |
| GET | `/cdp/{id}/json?token=` | 短期令牌 | 同上 |
| GET | `/cdp/{id}/json/activate/{targetId}?token=` | 短期令牌 | 激活标签页 |
| GET | `/cdp/{id}/json/close/{targetId}?token=` | 短期令牌 | 关闭标签页 |
| **PUT** | `/cdp/{id}/json/new?url=&token=` | 短期令牌 | 新建标签页（新版 Chromium 只接受 PUT） |
| WS | `/cdp/{id}/{任意路径}?token=` | 短期令牌 | CDP 主通道 |

### 地址重写示例

```bash
TOKEN=$(curl -s -H "Authorization: Bearer $T" \
  http://127.0.0.1:8730/api/v1/profiles/demo/cdp | jq -r .data.token)

curl -s "http://127.0.0.1:8730/cdp/<id>/json/version?token=$TOKEN"
```

原始（浏览器自己吐的）：
```json
{"webSocketDebuggerUrl":"ws://127.0.0.1:21001/devtools/browser/fe36…"}
```

经过网关：
```json
{"webSocketDebuggerUrl":"ws://192.168.3.6:8730/cdp/<id>/devtools/browser/fe36…?token=zwc_…"}
```

**这就是为什么跨机能用** —— 不改写的话，客户端拿到 `127.0.0.1:21001` 连的是它自己。

### 令牌规则

- TTL 默认 900 秒，可传 `?ttl=60..7200`。
- 只存 `sha256(token)`，数据库泄露不等于令牌泄露。
- 一个令牌只能用于一个环境；每环境最多同时保留 20 个有效令牌（防止反复点"取 CDP"把表撑大）。
- `ZW_CDP_MAX_CONN`（默认 8）限制单环境并发 ws。

## 五、数据（cookie / storage / 页面）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/v1/profiles/{ref}/cookies` | 导出。`?fmt=cdp\|netscape\|playwright` |
| PUT | `/api/v1/profiles/{ref}/cookies` | 导入。`mode=replace\|merge` |
| POST | `/api/v1/profiles/{ref}/cookies/clear` | 清空 |
| GET | `/api/v1/profiles/{ref}/storage?origin=https://a.com` | 读 localStorage（可重复传多个 origin） |
| PUT | `/api/v1/profiles/{ref}/storage` | 写 localStorage |
| POST | `/api/v1/page/navigate` | `{profile,url,new_tab}` |
| POST | `/api/v1/page/evaluate` | `{profile,expression}` |
| POST | `/api/v1/page/screenshot` | `{profile,format:"png",full_page}` → 字节流 |
| GET | `/api/v1/page/text?profile=` | 页面可见文字 |
| GET | `/api/v1/page/targets?profile=` | 标签页列表 |

```bash
# 导出为 netscape 格式（给 yt-dlp / curl 用）
zw cookie dump 小红一号 --format netscape --out cookies.txt

# 导入
zw cookie load 小红一号 --file cookies.json --mode merge
```

**两条硬约束**：

1. cookie 只能在 `running` 的环境读写。`stopped` 时磁盘上的 `Cookies` 是 OS 密钥加密的密文 ——
   接口直接返回 `409 STATE_CONFLICT` 并告诉你怎么做。
2. **页面类操作跑在"专属管理标签页"里**。程序的第一次页面操作会认领/新建一个 about:blank 标签，
   之后导航、截图、执行 JS、读写 localStorage 都在那个标签里进行。
   **不会**把你正在看的页面刷掉。

## 六、扩展库

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/v1/extensions` | 已安装的扩展（含 `bound_to` 反向引用） |
| POST | `/api/v1/extensions/install` | `{"path":"/abs/dir-or-zip"}` |
| DELETE | `/api/v1/extensions/{slug}/{version}` | 删除；**被环境绑定时返回 409 `EXTENSION_IN_USE`** |
| POST | `/api/v1/profiles/{ref}/extensions` | 绑定 `{slug}` |
| DELETE | `/api/v1/profiles/{ref}/extensions/{slug}` | 解绑 |

安装时校验 `manifest.json`、算 sha256、做防路径穿越（zip 里有 `..` 或绝对路径整体拒绝）。
zip 里多套了一层目录会自动纠正。

环境里的 `extensions` 存的是**库里的 slug**（老数据的绝对路径仍然兼容）。

## 七、代理库

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/v1/proxies` | 列表（**不含密码**，含 `upstream` 与 `used_by`） |
| POST | `/api/v1/proxies` | `{label,scheme,host,port,username,password,country}` |
| PATCH | `/api/v1/proxies/{id}` | 修改；`password` 传空串＝不改 |
| DELETE | `/api/v1/proxies/{id}` | 删除；被环境引用时 409 `PROXY_IN_USE` |
| POST | `/api/v1/proxies/{id}/check` | 检测出口 `{ok,exit_ip,latency_ms,country,error}` |
| POST | `/api/v1/proxies/check` | 不保存直接检测（body 同 POST 新增） |

> **带用户名密码的代理**不能写在 `--proxy-server` 里（Chromium 不支持，会静默连不上）。
> 知纹会自动生成一个 MV3 认证扩展来应答 `onAuthRequired`。
> 凭据不进命令行、不回显、不写日志。

环境里 `proxy` 存的是**上游地址（已剥凭据）**，`proxy_id` 引用库条目。两者都能用；
同时存在时以 `proxy` 为准。

## 十、错误码全表

| code | HTTP | 含义 | 该怎么做 |
|---|---|---|---|
| `UNAUTHENTICATED` | 401 | 令牌不对 | 检查 `ZW_ADMIN_TOKEN` |
| `CIDR_FORBIDDEN` | 403 | 来源不在允许网段 | 改 `ZW_ALLOWED_CIDRS` |
| `PROFILE_NOT_FOUND` | 404 | 环境不存在 | 先 `GET /profiles` |
| `NAME_TAKEN` | 409 | 环境名重复 | 换名字 |
| `INVALID_NAME` | 400 | 空名/太长 | —— |
| `INVALID_WINDOW` | 400 | 窗口尺寸越界 | 320×240 – 8192×8192 |
| `INVALID_PLATFORM` | 400 | 平台取值不对 | host/windows/linux/macos |
| `INVALID_RESTART_POLICY` | 400 | 重启策略取值不对 | never/on-failure/always |
| `INVALID_TIMEZONE` | 400 | 时区不合法 | 例如 `Asia/Shanghai` |
| `INVALID_URL` | 400 | 起始网址不合法 | 只接受 http/https/about/file/chrome |
| `INVALID_MODE` | 400 | cookie 写入模式不对 | replace / merge |
| `INVALID_ACTION` | 400 | 批量动作不对 | start / stop / restart |
| `INVALID_ID` | 400 | 标识含非法字符 | 字母数字下划线短横，4-64 位 |
| `UNKNOWN_FIELDS` | 400 | 传了不认识的字段 | 看可写字段全集 |
| `PROFILE_BUSY` | 409 | 被别的持有者占用 | 等租约过期或 `unlock`（本地）/ 让对方释放（跨机） |
| `STATE_CONFLICT` | 409 | 当前状态不允许 | 看 `state` 再决定 |
| `MAX_RUNNING` | 409 | 到并发上限 | 停几个或调大 `ZW_MAX_RUNNING` |
| `PORT_EXHAUSTED` | 409 | 端口池用尽 | 扩池或停环境 |
| `PORT_MISMATCH` | 500 | 端口被别的进程占用 | 清孤儿进程 / 改端口池（Windows 上常见是 Hyper-V 占了） |
| `SEED_IMMUTABLE` | 400 | 想直接改指纹种子 | 用 `fingerprint/reset` |
| `SEED_ALLOC_FAILED` | 400 | 找不到空闲种子 | 环境太多了 |
| `CONFIRM_REQUIRED` | 400 | 危险操作缺确认 | `confirm` 写环境名 |
| `ENGINE_NOT_FOUND` | 422 | 没找到内核 | 设 `ZW_CHROME_BIN` |
| `ENGINE_EXITED` | 500 | 起来就退了 | 看 `browser.log` |
| `LAUNCH_TIMEOUT` | 500 | 45 秒没就绪 | 看日志、查杀软、查端口 |
| `SPAWN_FAILED` | 500 | 进程拉不起来 | 查权限与杀软 |
| `CDP_DISABLED` | 409 | 环境关了调试端口 | 开 `cdp_enabled` |
| `CDP_UNAVAILABLE` | 502 | 取不到调试地址 | 重启环境 |
| `CDP_CONNECT_FAILED` | 502 | 连不上浏览器调试端口 | 环境可能刚崩 |
| `CDP_TIMEOUT` | 502 | CDP 命令超时 | 页面可能卡住 |
| `CDP_COMMAND_FAILED` | 502 | CDP 返回错误 | 看 message 里的原始错误 |
| `JS_EXCEPTION` | 502 | 页面里执行 JS 抛异常 | 检查表达式 |
| `NAVIGATE_FAILED` | 502 | 导航失败 | 检查 URL 与网络 |
| `SELECTOR_NOT_FOUND` | 502 | 找不到元素 | 选择器写错或页面没加载完 |
| `ORIGIN_REQUIRED` | 400 | 读 localStorage 没给 origin | `?origin=https://a.com` |
| `ORIGIN_INVALID` | 400 | origin 不是 http/https | —— |
| `PATH_NOT_FOUND` | 400 | 扩展路径不存在 | —— |
| `NOT_AN_EXTENSION` | 400 | 目录里没有 manifest.json | —— |
| `BAD_MANIFEST` | 400 | manifest.json 不是合法 JSON | —— |
| `BAD_ARCHIVE` | 400 | 不是合法 zip | —— |
| `UNSAFE_ARCHIVE` | 400 | zip 里有路径穿越 | 包被动过，别用 |
| `EXTENSION_NOT_FOUND` | 404 | 库里没有这个扩展 | —— |
| `EXTENSION_IN_USE` | 409 | 扩展被环境绑定 | 先解绑 |
| `PROXY_NOT_FOUND` | 404 | 代理不存在 | —— |
| `PROXY_IN_USE` | 409 | 代理被环境引用 | 先解绑 |
| `PROXY_INVALID` | 400 | 代理地址不合法 | —— |
| `PROXY_SCHEME_UNSUPPORTED` | 400 | 代理协议不支持 | http/https/socks5 |
| `LABEL_TAKEN` | 409 | 代理标签重复 | 换标签 |
| `PASSWORD_REQUIRED` | 400 | 没给主密码 | 设 `ZW_SYNC_PASSWORD` 或传 `password` |
| `KEY_FINGERPRINT_MISMATCH` | 412 | 主密码不对 / 包不是这台机加密的 | **不要重试**，先确认密码 |
| `REVISION_EXISTS` | 409 | 远端已有该版本 | 先 `pull` 对齐 |
| `REVISION_NOT_MONOTONIC` | 409 | latest 指针想回退 | 显式 `force=true` |
| `NO_REMOTE` | 404 | hub 上没有这个环境 | 先在源机 push |
| `NO_LATEST` | 404 | hub 上还没有发布过版本 | —— |
| `PROFILE_SYNC_OFF` | 400 | 该环境关闭了同步 | 开 `sync_enabled` |
| `SYNC_DISABLED` | 400 | 同步功能整体关闭 | `ZW_SYNC_ENABLED=true` |
| `EPHEMERAL_PROTECTED` | 409 | 临时环境禁止导出/同步 | 它定位就是"用完即弃" |
| `EXPORT_DISABLED` | 409 | 环境正在启停，稍后再导出 | —— |
| `BUNDLE_TOO_LARGE` | 413 | 包体超过上限 | 先停环境 trim 再导 |
| `IMPORT_INVALID` | 400 | 导入包不合法 | 确认是 `.zwp` |
| `BUNDLE_TRUNCATED` | 400 | 包被截断 | 重新导出 |
| `BAD_MAGIC` | 400 | 不是知纹的包 | 确认文件 |
| `UNSUPPORTED_VERSION` | 400 | 包格式版本过新 | 升级程序 |
| `MANIFEST_MISSING` | 400 | 包内缺 manifest | 包不完整 |
| `UNSAFE_PATH` | 400 | 包内有路径穿越 | 包被改过，别用 |
| `PROFILE_DIR_MISSING` | 400 | 环境目录不存在 | —— |
| `EMPTY_PASSWORD` | 400 | 空主密码 | —— |
| `DECRYPT_FAILED` | 400 | 解密失败 | 密码不对 |
| `HUB_NOT_CONFIGURED` | 400 | 没配 hub 地址 | `ZW_HUB_URL` |
| `HUB_UNREACHABLE` | 502 | 连不上 hub | 查网络/防火墙 |
| `HUB_BAD_RESPONSE` | 502 | hub 返回的不是 JSON | 中间有代理/网关在捣乱 |
| `SIGNATURE_REQUIRED` | 401 | hub 要求签名 | 客户端配 `ZW_SIGNATURE_SECRET` |
| `SIGNATURE_INVALID` / `SIGNATURE_EXPIRED` | 401 | 签名不对/时间戳过期 | 检查密钥与系统时间 |
| `STORAGE_READONLY` | 503 | hub 数据目录不可写 | 查挂载与权限 |
| `BLOB_NOT_FOUND` | 404 | hub 上没有这块 | —— |

| `LEASE_NOT_FOUND` | 404 | 没有这个租约 | —— |
| `LEASE_OWNER_MISMATCH` | 409 | 租约属于别人 | 用正确的 owner 释放 |
