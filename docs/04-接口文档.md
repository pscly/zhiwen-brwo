# 04 · 接口文档

> 三句话先记住：
> 1. 成功一律 `{"ok": true, "data": {...}}`；失败一律 `{"ok": false, "code", "message", "hint"}`。
> 2. `code` 是稳定字符串，给程序/AI 判断用；`message` 是给人看的；`hint` 是一句话建议。
> 3. 鉴权：`Authorization: Bearer <ZW_ADMIN_TOKEN>`（不设令牌时只允许本机回环）。

在线交互文档：启动后访问 **http://127.0.0.1:8730/docs**（FastAPI 自动生成）。

### 创建

```bash
curl -s -X POST http://127.0.0.1:8730/api/v1/profiles \
  -H "Authorization: Bearer $T" -H 'Content-Type: application/json' \
  -d '{"name":"小红一号","proxy":"http://127.0.0.1:7890","start_urls":["https://www.xiaohongshu.com"]}'
```

只有 `name` 必填。指纹种子留空会自动分配（且全局唯一）。

### 启动 + 返回

```json
{"ok":true,"data":{
  "profile":{"id":"4c1f…","name":"小红一号","state":"running","fp_seed":281456832},
  "cdp":{
    "gateway_ws_url":"ws://192.168.3.6:8730/cdp/4c1f…/devtools/browser/<GUID>?token=zwc_…",
    "playwright":"await chromium.connectOverCDP('ws://…')",
    "puppeteer":"await puppeteer.connect({ browserWSEndpoint: 'ws://…' })",
    "token_ttl":900
  },
  "local":{"pid":12345,"port":21001}
}}
```

## 三、CDP 网关

| 方法 | 路径 | 鉴权 | 说明 |
|---|---|---|---|
| GET | `/cdp/{id}/json/version?token=` | 短期令牌 | 发现接口，**地址已重写** |
| GET | `/cdp/{id}/json/list?token=` | 短期令牌 | 目标列表，**地址已重写** |
| GET | `/cdp/{id}/json?token=` | 短期令牌 | 同上 |
| WS | `/cdp/{id}/{任意路径}?token=` | 短期令牌 | CDP 主通道 |

### 地址重写示例

```bash
TOKEN=$(curl -s -H "Authorization: Bearer $T" \
  http://127.0.0.1:8730/api/v1/profiles/demo/cdp | jq -r .data.token)

curl -s "http://127.0.0.1:8730/cdp/<id>/json/version?token=$TOKEN"
```

原始（浏览器自己吐的）：
```json
{"webSocketDebuggerUrl":"ws://127.0.0.1:21001/devtools/browser/fe36…"}
```

经过网关：
```json
{"webSocketDebuggerUrl":"ws://192.168.3.6:8730/cdp/<id>/devtools/browser/fe36…?token=zwc_…"}
```

**这就是为什么跨机能用** —— 不改写的话，客户端拿到 `127.0.0.1:21001` 连的是它自己。

### 令牌规则

- TTL 默认 900 秒，可传 `?ttl=60..7200`。
- 只存 `sha256(token)`，数据库泄露不等于令牌泄露。
- 一个令牌只能用于一个环境。
- 源码里 `ZW_CDP_MAX_CONN`（默认 8）限制单环境并发 ws。

## 四、数据（cookie / storage）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/v1/profiles/{ref}/cookies` | 导出。`?fmt=cdp\|netscape\|playwright` |
| PUT | `/api/v1/profiles/{ref}/cookies` | 导入。`mode=replace\|merge` |
| GET | `/api/v1/profiles/{ref}/storage?origin=https://a.com` | 读 localStorage |
| PUT | `/api/v1/profiles/{ref}/storage` | 写 localStorage |

```bash
# 导出为 netscape 格式（给 yt-dlp / curl 用）
zw cookie dump 小红一号 --format netscape --out cookies.txt

# 导入
zw cookie load 小红一号 --file cookies.json --mode merge
```

**硬约束**：环境必须在 `running` 才能读写 cookie。
`stopped` 时磁盘上的 `Cookies` 是 OS 密钥加密的密文，读出来也没用 ——
接口会直接返回 `409 STATE_CONFLICT` 并告诉你先启动。

## 九、错误码全表

| code | HTTP | 含义 | 该怎么做 |
|---|---|---|---|
| `UNAUTHENTICATED` | 401 | 令牌不对 | 检查 `ZW_ADMIN_TOKEN` |
| `PROFILE_NOT_FOUND` | 404 | 环境不存在 | 先 `GET /profiles` |
| `NAME_TAKEN` | 409 | 环境名重复 | 换名字 |
| `PROFILE_BUSY` | 409 | 被别的持有者占用 | 等租约过期或 `unlock`（本地） |
| `STATE_CONFLICT` | 409 | 当前状态不允许 | 看 `state` 再决定 |
| `MAX_RUNNING` | 409 | 到并发上限 | 停几个或调大 `ZW_MAX_RUNNING` |
| `PORT_EXHAUSTED` | 409 | 端口池用尽 | 扩池或停环境 |
| `SEED_IMMUTABLE` | 400 | 想直接改指纹种子 | 用 `fingerprint/reset` |
| `CONFIRM_REQUIRED` | 400 | 危险操作缺确认 | `confirm` 写环境名 |
| `ENGINE_NOT_FOUND` | 422 | 没找到内核 | 设 `ZW_CHROME_BIN` |
| `ENGINE_EXITED` | 500 | 起来就退了 | 看 `profile.log` |
| `LAUNCH_TIMEOUT` | 500 | 45 秒没就绪 | 看日志、查杀软、查端口 |
| `CDP_DISABLED` | 409 | 环境关了调试端口 | 开 `cdp_enabled` |
| `CDP_UNAVAILABLE` | 502 | 取不到调试地址 | 重启环境 |
| `PASSWORD_REQUIRED` | 400 | 没给主密码 | 设 `ZW_SYNC_PASSWORD` 或传 `password` |
| `KEY_FINGERPRINT_MISMATCH` | 412 | 主密码不对 / 包不是这台机加密的 | **不要重试**，先确认密码 |
| `REVISION_EXISTS` | 409 | 远端已有该版本 | 先 `pull` 对齐 |
| `REVISION_NOT_MONOTONIC` | 409 | latest 指针想回退 | 显式 `force=true` |
| `NO_REMOTE` | 404 | hub 上没有这个环境 | 先在源机 push |
| `HUB_UNREACHABLE` | 502 | 连不上 hub | 查 `ZW_HUB_URL` / 网络 |
| `NOT_READY` | 503 | 内核缺失或数据库坏 | 看 `hint` |
| `UNSAFE_PATH` | 400 | 包里有路径穿越 | 包被改过，别用 |
| `INTERNAL` | 500 | 未分类 | 看 `<数据根>/logs/zhiwen.log` |
