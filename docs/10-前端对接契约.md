# 10 · 前端对接契约（v0.2，内部对齐用）

> 这份文件是**前端与后端之间的唯一契约**。改端点必须先改这里。
> 面向使用者的正式文档见 [04-接口文档](04-接口文档.md)。

## 0. 通用

- 全部响应：成功 `{"ok": true, "data": …}`；失败 `{"ok": false, "code": "...", "message": "...", "hint": "..."}`。
- 鉴权：`Authorization: Bearer <ZW_ADMIN_TOKEN>`。前端把令牌放 `localStorage['zw_token']`。
- 二进制端点（截图、导出包）**不套 `{ok,data}`**，直接返回字节流。
- 时间字段统一是 **Unix 秒（float）**，前端自己格式化。

### 2.1 创建/修改可写字段

`name, group_name, tags[], note, fp_platform, fp_platform_version, fp_brand, fp_brand_version,
fp_hardware, fp_timezone, fp_lang, fp_accept_lang, fp_disable_spoofing, fp_ua,
proxy, proxy_id, start_urls[], window_w, window_h, extensions[],
restart_policy, headless, ephemeral, trim_on_stop, sync_enabled, cdp_enabled`

创建时额外允许 `fp_seed`（一般留空自动分配）。

### 2.2 `extensions` 字段含义变更（v0.2）

`extensions` 存的是**扩展库里的 slug 列表**（例如 `["ublock-origin"]`），
后端在启动时把 slug 解析成库里的真实路径。老数据里的绝对路径仍然兼容（存在即用）。

### 2.3 指纹采样 `POST /profiles/{ref}/fingerprint/probe`

返回真机上真实读到的值，供"指纹是否自洽"的判断：

```json
{
  "profile_id":"…","name":"…","state":"running",
  "ua":"Mozilla/5.0 …","platform":"Win32","vendor":"Google Inc.",
  "ua_data":{"brands":[…],"mobile":false,"platform":"Windows"},
  "timezone":"Asia/Shanghai","timezone_offset":-480,
  "languages":["zh-CN"],"lang":"zh-CN",
  "hardware_concurrency":8,"device_memory":8,
  "webgl_vendor":"Google Inc. (NVIDIA)","webgl_renderer":"ANGLE (NVIDIA, RTX 3080 …)",
  "canvas_hash":"1a2b3c4d","audio_hash":"…",
  "webdriver":false,"screen":{"width":1280,"height":800,"colorDepth":24,"availWidth":1280},
  "fonts_count":42,
  "warnings":["时区与出口 IP 不一致"]
}
```

字段取不到时值为 `null`（例如无 GPU 机器上的 webgl），**不要**省略键。

## 6. 代理库

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/v1/proxies` | `{proxies:[{id,label,scheme,host,port,username,country,last_ok,last_check,last_exit_ip,has_password,used_by}]}` |
| POST | `/api/v1/proxies` | `{label,scheme,host,port,username,password,country}` |
| PATCH | `/api/v1/proxies/{id}` | 同上，`password` 留空＝不改 |

> 环境里 `proxy` 字段是"上游地址"的唯一真相；`proxy_id` 只是引用代理库的便捷来源。
> 设置了 `proxy_id` 时，后端把库里的凭据注入到代理认证扩展里（Chromium 的
> `--proxy-server` 不支持带密码，必须走扩展）。

## 10. 错误码补充（v0.2 新增）

| code | HTTP | 含义 |
|---|---|---|
| `PROXY_IN_USE` | 409 | 代理被环境引用，先解绑 |
| `PROXY_NOT_FOUND` | 404 | 代理不存在 |
| `PROXY_CHECK_FAILED` | 502 | 出口检测失败（连不上/认证失败） |
| `EXTENSION_IN_USE` | 409 | 扩展被环境绑定 |
| `EXTENSION_NOT_FOUND` | 404 | 库里没有这个扩展 |
| `IMPORT_INVALID` | 400 | 导入包不合法 |
| `EXPORT_DISABLED` | 409 | 环境正在启动/停止，稍后再导出 |
| `CIDR_FORBIDDEN` | 403 | 来源地址不在允许网段 |
| `EPHEMERAL_PROTECTED` | 409 | 临时环境禁止导出/同步 |
