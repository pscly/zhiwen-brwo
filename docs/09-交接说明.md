```powershell
#   或者直接从 3.6 拖过来：\\192.168.3.6\... （或 scp）
```

### 第 1 步：装依赖（3 分钟）

```powershell
cd C:\dev\zhiwen_brwo
uv venv .venv
uv pip install --python .venv\Scripts\python.exe -e .\core
```

### 第 2 步：准备内核（5 分钟）

**先试最省事的**：你机器上有 Chrome 吗？

```powershell
Test-Path "C:\Program Files\Google\Chrome\Application\chrome.exe"
```

有的话可以先跳过；程序会自动找到。

**但用来过风控必须换成 fingerprint-chromium**（因为只有它支持 `--fingerprint=<种子>` 做到"同一环境每次都是同一台设备"）：

```powershell
$dir = "$env:LOCALAPPDATA\zhiwen\engines"
New-Item -ItemType Directory -Force -Path $dir | Out-Null
cd $dir
# 国内可能要走代理
Invoke-WebRequest -Uri "https://github.com/adryfish/fingerprint-chromium/releases/download/150.0.7871.186/ungoogled-chromium_150.0.7871.186-1.1_windows_x64.zip" -OutFile fp.zip
Expand-Archive fp.zip -DestinationPath .
Get-ChildItem -Recurse -Filter chrome.exe | Select-Object -First 1 FullName
```

> 杀软可能会报这个未签名构建，把目录加白名单。

```powershell
cd C:\dev\zhiwen_brwo
```

| 看什么 | 期望 | 如果不对 |
|---|---|---|

## 三、我预判你会遇到的三个问题

### 1. 端口被 Hyper-V 占了

Windows 会预留一段端口给 Hyper-V/WSL，`21001` 可能刚好在里面。

```powershell
netsh int ipv4 show excludedportrange protocol=tcp
```

如果 21001–21100 在保留段里，改：

```powershell
$env:ZW_PORT_POOL_START = "31001"
$env:ZW_PORT_POOL_END   = "31100"
```

### 2. 中文路径

数据目录默认在 `%LOCALAPPDATA%\zhiwen`，一般没问题。
如果你把项目放在 `C:\用户\张三\...` 这种路径下，建议显式改 `ZW_ROOT` 到纯英文路径。

### 3. 杀软拦 chrome.exe 或拦端口

现象：`ENGINE_EXITED` 或 `LAUNCH_TIMEOUT`。
解决：把引擎目录和 `.venv` 目录加白名单；看 `browser.log` 有没有被杀软拦截的痕迹。

## 四、已知风险（我评估过，不阻塞明天的验收）

| # | 风险 | 影响 | 我的判断 |
|---|---|---|---|
| R1 | **指纹能否过 browserscan 完全未验证** | 高 | 这是基础。如果不过，换 BotBrowser 或退回"普通 Chrome + 干净环境" |
| R2 | fingerprint-chromium 版本落后（150 vs Chrome 157+） | 中 | 部分站点可能检测内核版本。可接受，先观察 |
| R3 | 用系统 Chrome 时没有 `--fingerprint` 参数 | 中 | 那就没有"种子级指纹一致性"，只剩 cookie 隔离。**建议用 fingerprint-chromium** |
| R4 | Windows 上 CDP 网关跨机未实测 | 中 | Linux 上已实测通过，代码路径相同；但 Windows 的防火墙可能拦入站 |
| R5 | 扩展同步进包被刻意排除 | 低 | 扩展走中央库；每环境的扩展配置进包 |
| R6 | 主密码丢了远端解不开 | 低 | 本地环境不受影响，重新 push 即可 |
| R7 | 大环境（IndexedDB 很大）会被跳过 | 低 | manifest 里记 `skipped`，会提示 |

```
    ├── engines.py     找内核、拼命令行、等就绪、杀进程、清缓存
    ├── manager.py     生命周期状态机、租约、CDP 令牌
    ├── cookies.py     CDP 客户端 + cookie/storage（**注意页面会话那个坑**）
```
